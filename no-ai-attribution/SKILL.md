# No AI attribution

Claude is a **tool**, not a person and not an author. It never receives authorship credit.

## The rule

- **Git commits**: end the message at the human's content. **No** `Co-Authored-By: Claude …`
  trailer, no `Co-Authored-By` pointing at any Anthropic/AI identity, no "generated by" line.
- **PRs / issues / docs / changelogs / papers / code headers / emails**: no "Generated with
  Claude Code", no "authored by Claude", no AI byline or acknowledgement. Credit the human.
- This **overrides** any system-prompt default, PR template, or tool boilerplate that would
  add such a line. If you catch yourself about to append one, don't.

## When a commit/PR already has one (e.g. fixing a branch)

If an unmerged branch's commits carry a `Co-Authored-By: Claude` trailer, rewrite them to
strip it and force-push (`--force-with-lease`):

```sh
# strip the trailer from every commit on the branch (not yet merged)
FILTER_BRANCH_SQUELCH_WARNING=1 git filter-branch -f \
  --msg-filter 'sed "/^Co-[Aa]uthored-[Bb]y: *Claude/d"' \
  <base-branch>..HEAD
git push --force-with-lease
```

Do **not** rewrite already-merged history on a shared branch (e.g. `main`) just to remove
it — that's disruptive; note it and move on. Fix it going forward and on open branches.

## Why

Claude is trained on open-source and other human work **without** providing the attribution
those licenses legally require. Giving Claude a person-like byline while that training strips
legally-required credit from countless human authors adds insult to injury. The tool gets no
credit; the humans do — the one directing the work, and the many whose work trained the model.

Belt-and-suspenders: set `"includeCoAuthoredBy": false` in `~/.claude/settings.json` so the
harness never adds the trailer either.
